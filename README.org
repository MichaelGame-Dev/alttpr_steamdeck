#+TITLE: ALttP Randomizer Launcher

This project makes it easy to start and resume
[[https://alttpr.com][The Legend of Zelda: A Link to the Past Randomizer]] on a Steam Deck or a system like
[[https://bazzite.gg][Bazzite]] or [[https://chimeraos.org][ChimeraOS]], without going to Desktop Mode. Setup happens
in Desktop Mode once; after that, everything runs from Steam's Game Mode with a controller.

It adds three entries to your Steam library:

- *New Seed*: generates a new seed with the official alttpr.com randomizer, patches your ROM and starts it
  in RetroArch.
- *Continue*: resumes your most recent seed.
- *Spoiler*: browses the current seed's spoiler on the TV with the controller.

#+begin_quote
*Note:* The code in this project was generated by AI and reviewed by a human.
#+end_quote

*Tested on:* Bazzite. Steam Deck (SteamOS) and ChimeraOS haven't been tested yet, but should work since
they're similar.

* Requirements
- The *Japan 1.0* ROM (/Zelda no Densetsu - Kamigami no Triforce/), MD5 =03a63945398191337e896e5771f77173=.
  A headered =.smc= is fine because =install.sh= strips the header. This project doesn't include or download
  the ROM; you need your own copy.
- RetroArch flatpak (EmuDeck installs it) with the *snes9x* core.
- Python 3 (included with Bazzite and SteamOS).
- Internet access when generating a new seed.

* Setup (once, in Desktop Mode)
1. Clone the repository somewhere permanent. The Steam shortcuts point at this path, so re-run
   =install.sh= if you move it.
   #+begin_src bash
   git clone <repo-url> ~/Games/alttp_randomizer
   cd ~/Games/alttp_randomizer
   #+end_src
2. Run the installer with your ROM:
   #+begin_src bash
   ./install.sh "/path/to/Zelda no Densetsu (Japan).sfc"
   #+end_src
   It checks the ROM, sets up a private Python environment in =~/.local/share/alttpr-launcher/=
   (nothing is installed system-wide), and creates the Steam entries. If it warns that the core is
   missing, open RetroArch → Online Updater → Core Downloader → /Nintendo - SNES / SFC (Snes9x - Current)/.
3. In Steam: Games → *Add a Non-Steam Game to My Library…* → tick *ALttP Randomizer - New Seed*,
   *- Continue* and *- Spoiler* → Add.
4. Switch to Game Mode and play.

To update later, run =git pull= and then =./install.sh= again. Your seeds and saves aren't affected.

* Usage
- *New Seed*: generates a new seed and starts it. If generation fails (offline, alttpr.com down), it loads
  your previous seed instead.
- *Continue*: starts the most recent seed. Use this to resume a run; launching /New Seed/ starts a different
  game. Settings are baked into each seed, so Continue never needs a preset.
- *Spoiler*: areas are listed on the left, and each one stays hidden until you press A on it, so scrolling
  doesn't spoil anything by accident. /Route to beat the game/ lists one item order that works.
  - D-pad/stick: move
  - A: reveal
  - L/R shoulder: page
  - B: back (B again quits)
  - Start: quit

** Picking a preset per launch
In Steam, right-click *New Seed* → Properties → *Launch Options*, and enter a preset name, e.g. =-open=.
It maps to =presets/open.json=; =open=, =-open= and =--open= all work. Leave it empty to use the config
default. An unknown name shows an error listing the available presets. From a terminal:
=./alttpr.sh new -open=.

Tip: to have both one click away, add /New Seed/ to Steam twice, rename one copy to
"ALttP Randomizer - New Seed (Open)", and give that copy the =-open= launch option.

* Files and saves
Seeds are stored in =~/Emulation/roms/snes/alttpr/=, or =~/.local/share/alttpr-launcher/seeds/= without
EmuDeck. Each seed comes with:
- =<seed>.json=: the seed ID, the file select code and the settings used
- =<seed>.spoiler.json=: the full item locations

Saves are RetroArch =.srm= files named after the seed ROM, so older runs keep their saves.

* Settings
Config lives in =~/.config/alttpr-launcher/config.env=:
- =PRESET=: which file in =presets/= to use. The default is =beginner.json=, which matches alttpr.com's
  Beginner preset: Standard start, basic item placement, every location reachable, and a guaranteed sword.
  =open.json= is the more typical "Open" setup.
- =RETROARCH_CMD=: the emulator command.
- =SEED_DIR=: where seeds go.

To make your own preset, copy one in =presets/= and edit it. Valid values are listed at
[[https://alttpr.com/randomizer/settings]]. The =cosmetics= section controls heart beep speed, heart color,
sprite and music.

* Troubleshooting
In Game Mode there's no terminal, so errors appear as pop-ups and everything is logged to
=~/.local/share/alttpr-launcher/launcher.log=.

* Uninstall
#+begin_src bash
rm -rf ~/.local/share/alttpr-launcher ~/.config/alttpr-launcher
rm ~/.local/share/applications/alttpr-{new,continue,spoiler}.desktop
#+end_src
Then remove the entries from Steam. Generated seeds and your RetroArch saves are left alone; delete the
seed folder (=~/Emulation/roms/snes/alttpr/=) too if you want the seeds gone.
